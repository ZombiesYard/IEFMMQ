\section{CLI 命令参考}\label{sec:appendix-cli}

\texttt{simtutor} 包提供以下 CLI 命令：

\begin{description}
\item[\texttt{run}.] 使用模拟环境适配器和预录制的场景文件执行模拟，并写入事件日志。
\item[\texttt{replay}.] 根据过程包验证现有事件日志，检查步骤顺序和状态机一致性。
\item[\texttt{score}.] 使用评分引擎对事件日志进行评分，产生遗漏计数、状态违规计数和总错误分数。
\item[\texttt{record-vlm}.] 对一组视觉观察执行 VLM 事实提取，并记录预测结果用于基准测试。
\item[\texttt{replay-bios}.] 通过遥测管线回放原始 DCS-BIOS 捕获数据，并可选择调用帮助生成循环。
\item[\texttt{validate}.] 根据 Schema 注册库中的指定 Schema 验证 JSONL 文件。
\end{description}

所有命令均接受模型配置覆盖参数（\texttt{--model-\allowbreak provider}、\texttt{--model-\allowbreak name}、\texttt{--model-\allowbreak base-\allowbreak url}、\texttt{--model-\allowbreak timeout-\allowbreak s}）和语言切换参数（\texttt{--lang}）。

\section{模型提供方配置}\label{sec:appendix-model-config}

模型访问通过环境变量配置，并在运行时验证：

\begin{description}
\item[提供方.] \texttt{SIMTUTOR\_MODEL\_PROVIDER} 选择 \texttt{openai\_compat}、\texttt{ollama} 或 \texttt{stub}。
\item[Base URL.] \texttt{SIMTUTOR\_MODEL\_BASE\_URL} 设置提供方端点。
\item[模型.] \texttt{SIMTUTOR\_MODEL\_NAME} 选择模型名称。
\item[超时.] \texttt{SIMTUTOR\_MODEL\_TIMEOUT\_S} 设置请求超时时间。
\item[凭证.] \texttt{SIMTUTOR\_MODEL\_API\_KEY} 是 \texttt{openai\_compat} 提供方所必需的。API 密钥在日志输出中会被遮盖。
\item[图像.] \texttt{SIMTUTOR\_MODEL\_ENABLE\_MULTIMODAL} 切换请求中的 base64 图像编码。
\item[语言.] \texttt{SIMTUTOR\_LANG} 选择 \texttt{zh} 或 \texttt{en}。
\end{description}
