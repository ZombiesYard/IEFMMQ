\section{CLI 命令参考}\label{sec:appendix-cli}

仓库中的原型 CLI 提供以下命令：

\begin{description}
\item[\texttt{run}.] 使用模拟环境适配器配合预记录的场景文件执行模拟，并写入事件日志。
\item[\texttt{replay}.] 对照程序包验证已有的事件日志，检查步骤排序和状态机一致性。
\item[\texttt{score}.] 使用评分引擎对事件日志进行评分，生成遗漏计数、状态违规计数和总错误得分。
\item[\texttt{record-vlm}.] 对一组视觉观察执行 VLM 事实提取，并记录预测以供基准测试。
\item[\texttt{replay-telemetry}.] 通过遥测流水线回放原始遥测捕获，并可选择性地调用帮助生成循环。
\item[\texttt{validate}.] 对照模式注册表中的命名模式验证 JSONL 文件。
\end{description}

所有命令接受模型配置覆盖（\texttt{--model-provider}、\texttt{--model-name}、\texttt{--model-base-url}、\texttt{--model-timeout-s}）和语言切换（\texttt{--lang}）。

\section{模型提供方配置}\label{sec:appendix-model-config}

模型访问通过环境变量配置并在运行时验证。配置项包括：

\begin{description}
\item[Provider.] 模型提供方，可选择 \texttt{openai\_compat}、\texttt{ollama} 或 \texttt{stub}。
\item[Base URL.] 提供方端点。
\item[Model.] 模型名称。
\item[Timeout.] 请求超时。
\item[Credentials.] \texttt{openai\_compat} 提供方所需的 API 密钥；密钥在日志输出中被遮蔽。
\item[Images.] 是否在请求中启用 base64 图像编码。
\item[Language.] 输出语言，选择 \texttt{zh} 或 \texttt{en}。
\end{description}
