\chapter{可复现性与研究工件溯源}\label{ch:implementation}

前两章方法论定义了基于证据的教学循环、视觉事实适配协议和形成性 Quest~3 先导实验。本章将这些方法与用于支撑所报告声明的研究工件连接起来，定义使结果具有可审计性的工件类别、权威规则和可复现性限制。凡决定声明溯源、约束模型权限或定义如何检查所报告结果的实现细节，均被纳入。

\section{研究工件与声明边界}\label{sec:impl-boundaries}

本研究的工件体系将程序知识、运行时逻辑、外部系统和导出证据分离。程序包存储 F/A-18C Lot~20 冷启动步骤、门控定义、遥测绑定、UI 目标和视觉事实绑定。运行时系统加载这些声明并产生证据包、模型提示词、验证决策、叠加层动作和事件日志。DCS World、外部遥测接口、Quest~3 显示路径、模型服务器和截图捕获属于外部系统。

这一边界防止证据在不同声明之间转移。生成的模型文本本身不被视为研究观察，它只有在通过相应的模式、映射、约束、基准测试或人工审查步骤后才成为可用证据。因此，论文报告三类研究工件：

\begin{itemize}
\item \textbf{声明性配置：}程序步骤、遥测映射、视觉事实本体论、UI 目标、来源策略规则和回放套件定义。
\item \textbf{生成证据：}JSONL 事件日志、试验摘要、帮助周期表格、基准测试预测、基准测试指标和质量门控报告。
\item \textbf{人工审查证据：}审查后的视觉标签、人工步骤编码覆盖、排除规则后的问卷记录，以及匿名化自由文本评论。
\end{itemize}

每个研究问题使用不同的证据单元。RQ1 在帮助周期粒度上检查：触发上下文、可用证据、模型响应、验证决策和叠加层结果。RQ2 在图像和事实粒度上检查：审查标签向量、预测、解析状态和逐事实错误。RQ3 在参与者和步骤粒度上检查：试验摘要、人工编码、问卷行和评论。VLM 基准测试数字不被用作参与者证据；参与者完成行不被用作每个模型响应正确的证明。

\section{RQ 层面的溯源}\label{sec:impl-provenance}

\paragraph{RQ1：教学循环的可审计性。}运行时系统写入追加式事件和分析导出，而非仅渲染暂态的头盔指导。一个帮助周期记录：触发上下文、遥测快照、活跃步骤、门控诊断、检索片段、可用的视觉事实、提示词构建元数据、响应状态、验证结果、叠加层执行状态，以及回退或修复元数据。相同的格式支持回放：记录的遥测流可以通过与实时运行时相同的遥测映射、程序门控条件、来源策略和约束契约。这是 RQ1 声明教学系统可审计的研究工件基础。

\paragraph{RQ2：视觉事实基准测试的可追溯性。}第~\ref{ch:evaluation} 章报告的所有 VLM 指标均复制自本地基准测试输出，如 \texttt{metrics\_base.json}、\texttt{metrics\_lora.json}、\texttt{benchmark\_summary.json} 和逐事实评分文件。正文中选定的基准测试图表复制自相同的报告资产。证据链为：座舱图像捕获、人工标签审查、双语监督微调行生成、LoRA 训练，以及使用固定提示词、模式、生成设置和指标计算的独立验证集基准测试。训练运行时间和损失值被视为训练报告溯源；所报告的声明依赖于基准测试 JSON 和审查标签。

\paragraph{RQ3：先导实验数据权威。}每个参与者试验由一个试验目录表示，包含事件日志、试验摘要、步骤编码、动作时间线、帮助周期表、会话元数据和质量门控报告。试验后表格提供经验、信心、NASA-TLX 维度、适用的教学特定评分、通用自定义用户评分和自由文本评论。分析应用三条权威规则：P08 当自动重构与人工审查不一致时使用人工步骤编码；P02 保留任务日志指标但排除问卷推导值，因为内部参与者 ID 不匹配；P09 在元数据记录的参与者修正后作为独立参与者分析。

这些溯源规则保持先导实验声明的边界。先导实验可以描述在一个小型形成性样本中观察到的完成情况、编码错误、原始工作负荷评分、自定义试验后评分、评论和教学交互计数；它不能支撑统计显著性、因果学习效应、记忆保持、迁移、工作负荷降低或更快完成的声明。

\section{可复现性限制}\label{sec:impl-repro-limits}

本仓库支持对手稿、导出分析表、回放夹具、基准测试摘要和选定图表的本地检查。完整实验重运行需要外部状态：DCS World、F/A-18C 模块、外部遥测接口集成、Quest~3 设置、模型部署访问、用于 VLM 适配的 GPU 资源，以及形成性参与者会话条件。因此，本论文区分\emph{研究工件可复现性}和\emph{完整实验重运行可复现性}。前者是本文所作的声明：所报告结果可追溯至存储的研究工件，并可检查其内部一致性。后者需要重建模拟器、硬件、模型和参与者上下文。

这一区分也解释了初始提案的角色。提案对于理解初始的 VR 场景动机和后续范围演化是有用的，但不用作最终系统结果的证据。结果章节中的声明绑定到已实现的程序包、运行时导出、基准测试 JSON、审查标签和先导实验材料，而非仅绑定到提案设计。
