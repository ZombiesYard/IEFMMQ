\section{CLI Command Reference}\label{sec:appendix-cli}

The \texttt{simtutor} package provides the following CLI commands:

\begin{description}
\item[\texttt{run}.] Executes a simulation using a mock environment adapter
with a pre-recorded scenario file and writes the event log.
\item[\texttt{replay}.] Validates an existing event log against a procedure
pack, checking step ordering and state-machine consistency.
\item[\texttt{score}.] Scores an event log using the scoring engine, producing
omission counts, state-violation counts, and a total error score.
\item[\texttt{record-vlm}.] Runs VLM fact extraction on a set of vision
observations and records predictions for benchmarking.
\item[\texttt{replay-bios}.] Replays a raw DCS-BIOS capture through the
telemetry pipeline and optionally invokes the help generation loop.
\item[\texttt{validate}.] Validates JSONL files against a named schema from
the schema registry.
\end{description}

All commands accept model configuration overrides (\texttt{--model-provider},
\texttt{--model-name}, \texttt{--model-base-url}, \texttt{--model-timeout-s})
and a language switch (\texttt{--lang}).

\section{Model Provider Configuration}\label{sec:appendix-model-config}

Model access is configured through environment variables:
\texttt{SIMTUTOR\_MODEL\_PROVIDER} (\texttt{openai\_compat} $|$
\texttt{ollama} $|$ \texttt{stub}), \texttt{SIMTUTOR\_MODEL\_BASE\_URL},
\texttt{SIMTUTOR\_MODEL\_NAME}, \texttt{SIMTUTOR\_MODEL\_TIMEOUT\_S},
\texttt{SIMTUTOR\_MODEL\_API\_KEY} (required for \texttt{openai\_compat}),
\texttt{SIMTUTOR\_MODEL\_ENABLE\_MULTIMODAL} (toggles base64 image encoding in
requests), and \texttt{SIMTUTOR\_LANG} (\texttt{zh} $|$ \texttt{en}). The live
runtime validates all required configuration at startup and redacts API keys
from all log output.
